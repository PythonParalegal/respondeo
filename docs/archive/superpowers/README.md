# docs/archive/superpowers — Superseded Superpowers Plans and Specs

Earlier iterations of "superpowers" (fragment-wrapper refactors, redact-tab
rearchitectures, and related workstreams) that have been either shipped
or superseded. Preserved for forensic reference.

## What belongs here

- `specs/` — specific feature specs from the old `docs/superpowers/specs/`.
- `plans/` — older multi-commit plans from the old
  `docs/superpowers/plans/`.

## What does NOT belong here

- Active superpowers work. If such work is re-opened, pull the relevant
  file back into `docs/specs/` or a fresh audit document.
- Durable lessons. See `docs/lessons/fragment-scope-rule.md` for the
  fragment-scope lesson extracted from these materials.
